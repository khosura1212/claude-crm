Webhook Enrichment — n8n

Kirim data lead ke workflow n8n untuk enrichment otomatis. Workflow n8n akan mengambil data perusahaan dari Apollo, LinkedIn, atau sumber lain lalu menulis kembali ke CRM via webhook response.

URL tersimpan di crm_settings.webhookEnrichment

Payload Format

Setiap request enrichment mengirim payload berikut ke n8n:

{ "leadId": "string — ID lead dari crm_leads_v2", "company": "string — nama perusahaan", "website": "string — domain perusahaan (jika ada)", "country": "string — negara lead", "iso": "string — standar ISO yang diminati", "stage": "string — tahap pipeline saat ini" }

n8n dapat merespons dengan data enrichment yang langsung tersimpan ke crm_enrichment via JavaScript postMessage atau manual update.
